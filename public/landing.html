01 / DOMAIN

Website & Domain Security

Deterministic URL verification that checks incoming links against the authoritative Base Official Domain Registry before any web page can deceive a human or AI agent.

  • 17 Verified Official Domains: Authoritative registry match for base.org, basescan.org, aerodrome.finance, and core infrastructure.

Critical Realities of Web3

Why Traditional Security Assumptions Fail

Phishers and scam token deployers exploit false senses of security. PayGuard is engineered around three non-negotiable realities:

HTTPS ≠ Legitimate Website

A valid SSL padlock certificate proves only that the connection is encrypted — not that the entity on the other end is genuine. Phishing sites obtain free, automated SSL certificates in under two minutes.

PayGuard Defense: Evaluates domain identity against authoritative Base ecosystem registries and flags typosquats (e.g. bases.org vs base.org).

Verified Source ≠ Safe Contract

Verified Solidity source code on block explorers simply means the code matches bytecode — not that it is safe. Malicious contracts regularly feature verified code hiding 99% sell taxes and transfer locks.

PayGuard Defense: Inspects contract bytecode logic, dynamic transfer restrictions, and GoPlus honeypot telemetry on Base Mainnet.

Token Symbol ≠ Authenticity

ERC-20 token names and ticker symbols are completely unreserved in EVM architecture. Anyone can deploy a token named "USDC" or "cbBTC" to deceive traders and automated trading agents.

PayGuard Defense: Compares contract addresses against the canonical Base token registry to identify impersonator tokens in wallets.
